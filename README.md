# Customer Churn Analysis

## 📊 Project Overview
This project analyzes customer data to identify patterns behind churn (subscription cancellation).

## 🔍 Features
- Data Cleaning
- Exploratory Data Analysis
- Machine Learning Model (Logistic Regression)
- Churn Prediction

## 🧠 Insights
- Low tenure customers churn more
- High monthly charges increase churn
- Monthly contracts are risky

## 🛠️ Tools Used
- Python
- Pandas
- Seaborn
- Scikit-learn

## 🚀 Outcome
Helps businesses reduce churn and improve retention
